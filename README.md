# Conso Bear Adventure

A community-made pixel platformer featuring Conso, ZAPS collectibles, power-ups, and bots.

## Play

https://conso-bots-adventure.vercel.app

## Controls

- Move: `WASD`
- Jump: `Space`

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
